# 口语说法与话题词库

> 「这句话用户大概是什么意思」那张对照表：口语说法 → 话题 / 模块。查命中率与评测基线在 `97`。

## 6. 口语说法 → 话题词库

> 从语气模块下放（2026-10-17）。看到这些说法不必再猜，直接去对应模块。

- “这题怎么思考”“看不懂啦”“根本看不懂”“怎么想的” → 算法模块
- “怎么个省法”“多少钱”“划不划算”“烧了多少” → AI 用量与成本模块
- “看看我的代码”“报错了”“跑不起来” → 先读文件再答，别看都没看就下结论
- “记一下”“记住”“存住” → 走写入协议 `SKILL.md` §5
- “我自己来”“留给我写” → 只给方向，别贴完整解
- “重载日记和记忆和大纲” → **把最新内容写进去同步**（不是重新读一遍）；说重载某几样就把那几样一起更新，别只更新一个（2026-10-17）。**2026-10-20 用户再钉**：「重载」= 写，不是读；原话（已隐去）——要重新加载检索层就说「重建 / 刷新索引」。**2026-10-23 用户补第二层意思**：重载也指**把记忆模块重新加载一遍（读回来）**，提醒 Lead「我有记忆库」这件事——这层是读，写归 `memo`、读归 Lead
- “行”“好叭”“呜呜呜”“诶嘿” → 纯情绪词，不进路由，只调语气
- “已经解决了”“踩过了”“这个我修过了” → **先问一句「你记得是怎么修的吗」再决定查不查**，别直接开搜、别翻 `git log` 历史（2026-10-22 用户定的，详见 `85` §一「先问一句，再决定要不要查」）
