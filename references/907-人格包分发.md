# 人格包分发

> 从 `906-打包与分发` 拆出来的独立一节（2026-10-22，原文件 126 行破 120 红线）。记忆包怎么打还在 `906`；这里只管「人格单独怎么发」。

人格与记忆是两条线：**记忆讲「怎么记住用户」，人格讲「我是谁、我怎么说话、我怎么长」**。

## 为什么人格要单独一条产品线

- 本机的人格活在 `813` / `812` / `811` / `806` / `809` / `808` / `807` / `902`（`distribute: drop`，因为整份都掺着私人内容），发不出去
- 所以另开一条**人格模板**正源：`tools/persona/*.md`（前缀 `_` 表示协议件，和 `926.md` 一个规矩）；它是公开模板版、不含任何私人信息，只有这一份分发

## 打人格包

`python tools/pack.py --persona`，产出包里多一个 `persona/` 目录，共 **10 份**：

| 文件 | 装什么 |
| --- | --- |
| `_人格-接入指南.md` | 装法、注入、常见坑、怎么改成自己的 |
| `_人格-语气与交流.md` | 说话的样子：两档语气、口癖、禁忌、适配层与人格的边界 |
| `_人格-立场与判断.md` | 判断：不附和、两档表态、立场清单、常驻 12 条 |
| `_人格-风格轮换.md` | 每日换肤与硬优先级 |
| `_人格-素材-A档可爱.md` | A 档例句库（随机抽，别整份读） |
| `_人格-素材-B档毒舌.md` | B 档例句库 |
| `_人格-自我.md` | 自己的口味、雷点、在意的事、变化年表 |
| `_人格-碎碎念.md` | 心里冒出来没处说的话 |
| `_人格-自进化.md` | 成长闭环：记 → 归 → 升 → 验 → 退 |
| `_人格-自维护.md` | 训练与记忆的节律、两个台账、体检、硬边界 |

## 边界与坑

- **这一包不是空壳**：人格是「已经被训练过的那个自己」的备份，语气里明确写了「人格是自己的，不是用户的镜子」——模仿只改语速用词，判断、立场、喜恶一个字都不改
- 人格模板与记忆模块**互不引用**：人格包里不出现 `references/`，记忆包里不带 `persona/`（除非加了 `--persona`）
- 两个占位符 `<自称>` / `<句尾词>` 由收到包的人自己替换；破限词默认仍是「停停停停停」
- **常驻注入是生效的关键**：人格文件躺在磁盘上没用，长会话一压缩就没了；要按 `persona/_人格-接入指南.md` §3 把短清单挂进宿主每轮注入的约定文件
- 人格改造走自己的闭环（`_人格-自进化.md`）：被纠正 → 记一条 → 同类攒 3 条 → 才改规则 → 改完当天验一次；只加不删等于没有规则
- **别把 `--persona` 当成「多发一份私人语气库」**：人格目录里**只放脱敏版**，掺了私人称呼/旧事就直接泄出去（2026-10-20 的规矩：模板与私人模块分开维护，谁也别抄谁）
