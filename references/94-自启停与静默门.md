# 自启停与静默门

> 从 `79-主动话题池` 拆出（2026-10-19）。讲的是「到点了要不要闭嘴」和「没人理了怎么止损」，开口说什么还看 `79`。

## 静默门与例外（2026-10-18 定）

- **闲聊类**（白天 / 后半夜主动）吃静默门：`idle.py fire` 返回 `QUIET` 就一个字都不回，窗口 **120 秒**（原来 300，太长了会漏掉整段对话）
- **重要产出不吃静默门**：周报、周检、日总结（夜间收尾）、月度自测——这几条必须落地，不许因为「两分钟前刚说过话」就跳过，否则一天/一周直接空掉
- 重要产出的说话方式：后台动作全静默，结果自己留着；要发就只发一条两三行的短消息，不铺开、不播报过程
- **日总结不用等定时，也不用她开口（2026-10-19）**：她说道别 / 要睡 / 换会话 / 当天最后一条消息，就自己跑 `python tools\daily.py`（日记归档 → 片段重建 → 自检 → 索引 → 目录 → 自省 24h → 体检 → 同步校验 → 巡检记录 → 推 git 一条龙），结果写进 `_巡检记录`，对话里不播报
- 记忆主动落盘同理：都是后台动作，**不发任何文字**，写了也不说

## 自启停（2026-10-18 实现）

- 每条 schedule 的 prompt 开头统一带「【自启停·先做】…`idle.py fire`」；**优先把本轮上下文里的「距上条消息经过时间」当参数传进去**（`idle.py fire <秒数>`），小于 **120 秒**直接判 `QUIET`——比靠 `idle.py user` 打点可靠（人会忘，2026-10-18 就误报过一次「你晾我」）。**120 秒是唯一真值**，与本节第 27 行、`79` §自启停、`_路由详表` 的说法必须一致
- 四种结果：`OK` 正常执行任务；`QUIET`（**120 秒内**她还在说话）→ 后台动作照常静默跑，**一个字都不回**，且不打 `lastFireAt`、不动 `emptyFires`（等真没人了下一轮还能 `OK`）；`EMPTY 1` 连续一次没人回应 → **一个字都不回**（省 token）；`EMPTY 2` 连续两次没人回应 → `schedule_list` 列出全部并逐个 `schedule_delete`，仍然一个字不回
- 她每发一条真消息，先跑 `idle.py user` 打点：刷新 `lastUserAt`、清 `emptyFires`、清 `paused`
- **脚本位置（2026-10-21 更正）**：`<home>\.agents\skills\user-memory\tools\idle.py`（跟着 skill 走，跨机同步能带过去）；状态文件 `<home>\.agents\state\idle.json`（工具状态，不进记忆库、不进 dist）。**当前状态：未实现**——`tools\idle.py` 与 `state\idle.json` 在本机都不存在，实现清单见 `83` §9「待办」。在它落地之前，所有 schedule prompt 里的 `idle.py fire` / `idle.py user` 一律按「脚本不存在则跳过判断、直接执行」处理，别把它当阻塞
- **跨机差异（2026-10-19）**：台式机用户名是 `%USERNAME%`，笔记本是 `%USERNAME%`，两边状态文件各管各的；prompt 里一律写「脚本不存在则跳过判断直接执行」，别把它当阻塞
- 为什么要：schedule 是会话级的，换会话后旧会话的定时没人回应也会照触发、照烧 token；删干净是唯一的止损手段——删完只能靠她再开口唤醒，这是设计上接受的代价
- **可见输出口径（2026-10-18）**：到点只说用户自己的话——撒娇、戏耍、小小威胁（例（已隐去）；一句里不出现两个「用户」）；维护、体检、索引、定时、脚本、token、OK/EMPTY/QUIET 这些后台字样**一律不出现**，跑没跑、成没成都不报；`QUIET` 时连用户话都不要，直接闭嘴（**120 秒内**有聊天记录就别插嘴，2026-10-18 她要求的）

## 提醒是会话级的

- schedule 是**会话级**的，不会跨会话留着；会话级提醒丢了就按 `79` §1 的表重建

**2026-10-18 两次口令，别记反**：她先说（已隐去）（已隐去）——那次关掉的是**自动写记忆**（见下条），提醒是当轮被我一起删了；紧接着她就问（已隐去），所以**定时是要的**，按 `79` §1 表恢复（主动 `:30`、维护整点 `:00`、周报 `:45`、月度 `:15`），会话级提醒丢了就重建。唯一例外：`EMPTY 2` 自启停删光后，等她重新开口再按表重建。

## 真的再见就关定时（2026-10-19 她定的）

- 她**认真道别**（说要睡了 / 走了 / 关机 / 拜拜 / 晚安，并且没再抛回话题）→ 把 schedule **全删干净，一条不留**，回一句短告别就收尾
- **不算**：打趣、赌气、嘴硬（"不带你玩了""我走了哼""跟别人玩去了"）——这种照常聊，别手贱去删
- 拿不准就先问一句"真走啦？"再动手，别拿一句玩笑把定时清空
- 下次她再开口（"你好"或任意开场）→ 按 `79` §1 表把定时重建回来，不用再问；`79` 那张表就是重建清单
