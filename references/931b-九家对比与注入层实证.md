## 注入层实证（2026-11-01）

918 §8 记的是「系统提示词这一层（未实现，原理先记）」。本次 7 家外部实现里 **4 家真的往系统提示词注册了固定段**，可当照抄对象：
- `dsh-linghun` `index.js:362-396`：3 段，order `0` / `0.2` / `0.5`，`interpolate:false`
- `dsh-pua` `lib/index.js:39-56`：1 段，order `120`，**条件文本**（禁用或子代理时返回空串）
- `clearai-dsh` `clearai-kernel.js:5705-5713`：表驱动 + **双语段**，order 400 / 410 / 420
- `dsh-dream` `lib/automatic.js:83`：用 `context()` 而非 `section()`，order 4100

反向口径同样成立，且是三种不同走法：`dsh-engram` 走每轮 plugin 来源 user 快照（README:339 / 347 说明这是为了前缀稳定）；`@furongjun1999/dsh-memory` 走 prompt assemble 钩子（`lib/hooks.js:728`），不用 `section()`；`muche-dsh-plugin` 干脆不建 dsh 会话（`lib/index.js:6-12`）。

与 `908-记忆自动注入.md:103-109` 的对照：908 写「开关照 genui 先例存 settings（`promptEnabled`），**不 patch 第三方包**」——外部 4 家全部是**自己一个独立插件包**注册段，印证这条判断；另外灵枢 `src/hooks.ts:57` 的「打断 `{{`」与 908:108「`{{变量}}` 严格插值、缺值即抛」是同一个坑，两处互证。
