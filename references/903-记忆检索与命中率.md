# 记忆检索与命中率

> **2026-10-24 起顺序统一成「整篇优先」（Lead 定的）**：主动检索的**第一入口是 `python tools/memread.py "原话"`**——命中大类就把该大类模块整篇读进来；整篇不够、或者要精确定位到某一句时才下沉到片段层：`frag.py search 关键词` 定位 → `frag.py pack --query "关键词" --main 3 --random 2` 组包 → 主片段精读、次片段随机读 → 还不清楚再回原模块按行读。**为什么翻过来**（2026-10-20 她原话）：切片靠词面匹配，词面不对就零命中，她要求（原话已移除）；整篇读少了「切错、搜不到」一整类故障，代价是 token，她明确说不省这个。片段层仍然有用，只是从「唯一入口」退成「精确定位与兜底」。口径与 `SKILL.md`、`918` §3 一致。
>
> **输出预算（2026-10-24 加的）**：`memread.py` 默认最多 **12000 字符 / 300 行**，超出按**模块边界**截断、不砍半句，并打一行提示告诉你停在哪个模块第几段、怎么用 `--offset <段号>` 接着读；显式要整篇时加 `--full` 绕过预算。实测旧版一条查询直出 71097 字符 / 1228 行，会被宿主不可控截断。
>
> **2026-10-19 起片段层切分与检索细节**：模块已切成「一个片段一个文件」（`fragments/`，总表 `fragments/INDEX.md`，★=主片段）。
>
> **2026-10-20 加同义扩展**：`frag.py search` / `pack` / `auto` 的查询会先过 `tools/synonyms.py` 扩展一遍——她要求（原话已移除），查询里就同时带上 `emo/情绪/低落`；扩展词权重 `EXPAND_W = 0.45`，只加召回、不抢排序。
>
> **2026-10-23 输出层折叠**：`frag.py search` 默认把同 `part.base` 的命中合成一行「区间摘要」——分数取组内最高、位置跟最高分那片，id 连续写 `202.002–202.016`、不连续写 `202.001, 011–015`，尾标〔同源 N 片 · 合计 M 字〕；只压行数不压信息，不拼正文、不截断片段内容。`--k` 按折叠后的组数计，要逐条碎片看旧行为加 `--expand-parts`（`auto` 走 `pack`，那边已有同源归并）。理由是 `MAX_LINES=4` 会把同一段落切成多片，八条命中可能是同一个知识点。
>
> 对标业界补的一层：**怎么保证该读的时候读得到**。协议本身在 `SKILL.md`，本文只放方法与自测。
> 出处与链接统一收在 `912-参考资料与出处.md`；评测基线与口语词库拆到 `915-检索评测与词库.md`，本文不再重复。

## 1. 我们的三层，对应到哪儿

| 层 | 业界叫法 | 我们的文件 |
| --- | --- | --- |
| 每轮都在 | core memory | 两份 `AGENTS.md`（自动注入）+ `SKILL.md` + 语气模块（本机编号 `813`；没建就不占位） |
| 按需读 | archival memory | `references/` 下的模块 |
| 翻历史 | recall memory | `日记/` 日记、`921.md`、`archive/` |

**顺序**：core → archival 路由（命中才读）→ 都没有才 recall。别一上来就翻日记。

## 2. 检索三步（缺一步就不算查过）

1. **关键词**：路由表 → 命中模块里检索 → 按 `offset`/`limit` 读那几行，不整份读。有索引时用 `python tools/memdb.py search "关键词"`，它直接按分数给 `doc:line`。
2. **一跳扩散**：条目带 `relates_to` 或 `[[id]]` 就跳一跳（只跳一跳，别连环）。
3. **历史兜底**：只在问“以前 / 上次 / 为什么这样”时，查日记（近 2–3 天 + 随机 1 篇）与 `921`。

## 2.5 主动检索（2026-10-19 加的：不让检索等关键词）

- **默认行为**：用户一句正常的话进来，**先自己判断要不要翻**，不要求他说「查记忆」才动作。判据三条，中一条就翻——① 出现人称代词（我 / 你 / 我们 / 他 / 用户）② 出现「以前 / 上次 / 又说 / 还是 / 那个」这类指代旧事的词 ③ 话题命中路由关键词但细节可能不在本轮上下文里
- **一句话就能翻**：`python tools/frag.py auto "<用户刚说的原话>"`——原话整句丢进去，脚本自己抽词、判稀有度、选主片段；比 `search` 省一步（不用先想关键词）。输出约 300～500 token，够用就停
- 用户问「咱记忆呢」「还记得吗」「之前说的」三句是最强的触发信号，**看到就必须翻，不许凭印象答**
- 翻完**直接用**，不说「我去查了记忆」「按 `903` 模块记载」；翻不到就说没记，不编
- 边界：不主动翻敏感模块（健康、情绪这类）；闲聊轮次（斗图、天气）不翻，别把每句话都当检索请求
- **写完必须切块（2026-10-20 补）**：`python tools/memgit.py commit/autosync` 现在会在提交前自动 `frag.py build`，但手工改完模块不走 memgit 时，仍要自己 build 一次——`fragments/` 不进 git，两边机器各建各的，不 build 就等于检索层还是旧的
- **写完必须回读验证（2026-10-20 补，她要求（原话已移除））**：她只感知结果，分不清哪一步断，所以质检不许外包给她——每次落盘后立刻 `frag.py search <刚写进去的关键词>`，至少一条命中才算存好；没命中就当场修（查是否被 `_` 过滤、是否没 build、是否在不进 git 的层），修完再说「存好了」
- **每轮注入指针行（2026-10-20 她要求，改自 `recall.py`）**：她要求（原话已移除）。现在 `MEMORY_RECALL_EVERY` 默认 `1`（每轮都注入），卡头固定带一行 `POINTER`（记忆库路径 + 跑 `memread.py` 的口诀）；无相关内容时也至少注入这一行；`921` / `changelog` 加入 `BANNED_DOCS`，不让元日志当内容注入。改完用 `python tools/recall.py text "话题"` 和 `echo 话题 | python tools/recall.py hook --host plain` 验一遍
- **没命中就翻目录树（2026-10-20 她要求）**：片段层一条都没命中时不许空手回去——退回 `fragments/` 与 `references/` 的**文件名**（含模块目录名），只看名字，用名字里的词自己给自己加命中，再顺着文件名去读那几片。实现是 `tools/frag.py` 的 `filename_fallback()`，`search` / `pack` 已自动接上；文件名也零命中才说没记

## 3. 命中打分（三因子，别只认关键词）

- **相关性**：命中路由关键词 +2；命中用户的原话用词 +3
- **重要度**：在 `SKILL.md` 1.5 速查表里 +2；踩过并被纠正的红线 +2
- **近期性**：`updated` 7 天内 +1，30 天内 0，超过 30 天 −1
- 取总分最高的 1–2 个模块读，别贪多；同分时读**文件更短**的那个

> 这套打分已经在 `tools/memdb.py` 里实现：稀有权重 `1/(df+1)^0.6` + 最稀有词门控（没命中就 ×0.25）+ 路由关键词 ×1.3 + 重要度 + 近期性 + 标题行 ×0.6。**手算用来决定读哪个模块，脚本用来决定读哪一行。**
>
> 片段层（`frag.py`）走的是另一套、更接近标准 BM25 的实现：`k1=1.2`、`b=0.75` 的 tf 饱和 + 文档长度归一化 + 标题词双倍 + `idf = log((N+1)/(df+0.5))`。两套不冲突——`memdb.py` 管行级、`frag.py` 管片段级。

## 4. 写入：补两种状态

- **DELETE / retire（2026-10-24 改成软删）**：要让一条记忆失效，走 `memwrite.py` 的 `op: "retire"`——行尾挂「（已退休 YYYY-MM-DD：理由）」，**正文一个字不删**，`frag` 切片时含标记的行不进片段、不被检索命中，`memdb` 标 `deleted=1` 并留审计。`old` 定位行、必须唯一；`reason` 必填（删记忆比写记忆危险，不能静悄悄发生）。**只有她要求（原话已移除）才硬删正文行**，那种情况在 `921` 留一行「按请求删除 X」，不留内容只留动作。依据下一条：本库没有容量压力；她要求（原话已移除）。
- **TTL（临时信息）**：条目尾挂 `（TTL: YYYY-MM-DD 过期）`，到期**不是删掉**，是改写成「那次…后来怎样了」收一句——过期的是时效，不是发生过。真正删除只在她要求（原话已移除）时做（2026-10-20：本库没有容量压力）
- **槽位（治矛盾）**：可选标记 `〔槽位: 城市〕`；同槽位来了新值就直接改旧行（除非用户要保留历史，那走 supersede）
- **SOURCE（治「测试员的话被当主人原话」，2026-10-24 shiori-old 定）**：条目尾挂来源标——`（样本）`＝造出来的；`（测试记录，非本人原话）`＝测试 / 演练里的对话；`（来源不明）`＝查过了查不出出处；**无标＝默认按 `user-original` 读（她本人原话）**。标记防的是「假货冒充真货」，不是「真货需要自证」——所以默认档不标，标了反而是两套正标记加一个负标记。**必须挂在正文行尾**：`frag` 切片只带正文，说明性文字在切片面前是流沙——只写在文件头，读的时候一个字都到不了上下文（实测 `101` 的样本说明被切成单独一片，问某天干了什么时它挤不进去）。写入端 `memwrite` 的 `source` 字段自动挂尾标，`801` / `001` / `003` 缺它就拒；`101` 靠行尾标，不额外要模块级 source。

## 5. 月度反思（consolidation）

每月体检多做一步：翻最近 30 天日记，抽**最多 3 条**已经稳定的结论（不是流水账），回写进对应模块并记日志。目的：让检索变准，不是让库变薄——**别为了「薄」去合并或删她的日子**（2026-10-20）。

## 6. 索引库（`tools/memdb.py`）

markdown 是唯一事实源，SQLite 只是索引 + 审计层，删了重跑 `index` 就能重建。**下面的数字都带日期戳，是当时的快照、不是现值**；要现值跑 `python tools\memory_check.py`（模块数）与 `python tools\frag.py lint`（片段数），两者口径不同别混用（2026-10-17：27 个文件、789 行、148 KB；2026-10-19：33 个文件、1312 条行级条目；2026-10-21：48 个模块、536 个片段）。

| 命令 | 干什么 |
| --- | --- |
| `index` | 全量重建（改完 md 就跑） |
| `search "词"` | 打分检索，直接给 `doc:line` |
| `quiz` | 20 题自测，出「命中 / 漏检 / 语料缺失」 |
| `conflicts` | 同槽位多值（矛盾检测） |
| `expire` | TTL 过期条目 |
| `forget "子串" --yes` | 软删除 + 审计（md 还得手动删） |
| `stats` | 模块数 / 条目数 / 库大小 |

在 `tools/` 下跑：`python memdb.py search "语气"`。

## 7. 命中率怎么量

评测基线（四档递进、`recall@1/@3/@5`、MRR）、真歧义的判定、「题库不许进语料」的铁律、口语说法 → 话题词库，都在 **`915-检索评测与词库.md`**。本节只留一句口径：**`recall@3` 掉到 90% 以下就先补同义词组，别急着改算法；单次波动不算回归。**

## 8. 2026-10-20 判断：命中率低不是算法问题，是写入被关了

- 她要求（原话已移除）。实查结果证实她对在前半句：`AGENTS.md` §5 那条「只有她说记才写」从…应该已作废却没真改，而它是每轮被注入的那份——三天里实际是「只取不存」。
- 所以修检索层（片段、同义词、钩子、验证工具）只能让「已存在的少量内容」被捞得更准，源头断了再精也没用。**先修写入，再谈检索。**
- 向量库：不上。理由① 可移植是她定的红线（本机模型把 skill 变成需装环境的东西）；② 源头刚恢复，得先看一周正常写入后的真实命中率再定；③ 2148 行时关键词扫只要 9.8 ms，换向量要付每轮 1〜2 秒冷启动 + 500〜700 MB 内存。
- 冻结一周（2026-10-20〜2026-10-27）：只记录、不改引擎。一周后若仍接不住，再拿真实数据谈向量。
- （2026-10-26）**零 API 是硬定位，不是省钱技巧**：记忆库全链路不调任何模型——tokenize（分词）、打分排序、同义词扩展、元规则降权，全在本地 `tools/recall.py` 里跑，一分钱不花、也不看 provider 脸色。对比 `dsh-feiyu-mood`：它不接额外 API key，但每轮心情判定要走一次当前 provider 的小调用（README 第 5 行自述「不是关键词硬猜，也不是随机数」；第 243 行「判断 = 算不算这一次心情（花钱那步）」），并且把「判断」和「说出口」分成两级（confidence 低于门槛只记后台、不进对话）。借它只借结构（confidence 门 / 按来源分口径 / reason 强制过去式），**绝不引入模型调用**。她要求（原话已移除）。
